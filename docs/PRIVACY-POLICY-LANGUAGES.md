# English / Korean Surfside Privacy Policy

The church's canonical public privacy policy is generated by Surfside Tools, not by manually editing the page contents.

- English: https://surfsidefellowship.org/privacy-policy/ — existing page and shortcode `[surfside_privacy_policy]`.
- Korean: https://surfsidefellowship.org/privacy-policy-ko/ — new page, generated on the next WordPress admin visit after deployment, using `[surfside_privacy_policy_ko]`.
- Both editions use the same styling, reciprocal language links, and an effective date of November 2, 2026.
- The Korean page is created on `admin_init` only once per version; existing manually written content at the slug is not overwritten. It is intentionally not set as WordPress's canonical privacy-policy page.

## What changed
The policy now covers Surfside's website, mobile apps, and television apps (Samsung Tizen, Roku, Fire TV, Apple TV, Google TV). TV apps require no account and request no entered personal details. Their WordPress/Cloudflare streaming and content-delivery services may process IP addresses and other request diagnostics. The church does not create personalized TV viewing profiles or share data for targeted advertising.

The prior account, saved-content, contact/prayer, notifications, security, retention/deletion, and children's-privacy provisions remain in both versions. No claim is made about exact Cloudflare/host log retention without reviewing provider settings.

## Validate after merging and deployment
1. CI PHP lint succeeds, including the new Korean file.
2. Deploy the plugin, then open WordPress administration once to provision the Korean page.
3. Browse each public URL signed out; confirm both pages render and each language link works.
4. Verify the English and Korean versions contain every major section and the same 12-month contact/prayer email retention, 90-day completed prayer list deletion, and 30-day verified deletion request deadline.
5. Confirm TV streaming/Cloudflare disclosure is accurate; the Korean deletion-help link explicitly labels the English-language target.
6. Enter the Korean URL into Samsung Seller Office if its validation continues requiring it.

The Korean wording should be reviewed by a proficient Korean speaker for any formal legal/regulatory assurance. Do not publish a claim that technical request data is never processed.
